1. Big Picture of the Assignment

Your assignment is not just about separate topics. It is one full system.

You are likely building a program where:

  • A Student stores student information
  • A Course stores course information
  • A Program groups related courses
  • The system reads and writes data using files
  • STL containers store objects
  • Algorithms help search, display, or sort data
  • Error handling protects the program from bad input or missing files

2. Suggested Class Design

Student

Stores student details and maybe the courses they are taking.

Course

Stores course details and maybe a list of students enrolled.

Program

Stores program details and a list of courses inside that program.

class Course;
class Program;

class Student {
    std::string name;
    int studentId;
    std::vector<Course*> courses;
};

class Course {
    std::string code;
    std::string title;
    std::vector<Student*> students;
};

class Program {
    std::string name;
    std::vector<Course*> courses;
};
These relationships are a good example of aggregation because one class keeps pointers or references to objects that can still exist on their own.

3. Aggregation

Aggregation means one class has another object, but does not fully own its lifetime.

Example: a Course has Student objects, but the students still exist separately.

class Course {
    std::string courseName;
    std::vector<Student*> students;
};
Concept Meaning
Aggregation A class stores another object by pointer or reference, but the object can exist independently.
Why useful Prevents unnecessary copying and shows relationships clearly.
Be careful with pointers. If an object is destroyed, a stored pointer to it becomes invalid.

4. Strings

You will use std::string for names, IDs, program names, course codes, and file content.

std::string studentName = "Tom";
std::string courseCode = "OOP345";

if (studentName == "Tom") {
    std::cout << "Match found" << std::endl;
}

Common String Operations

name.length();
name.empty();
name += " Huynh";
getline(std::cin, name);
Good habit: pass strings as const std::string& when you do not want to copy them. 
void displayName(const std::string& name) {
    std::cout << name << std::endl;
}

5. Containers

The most likely container for this assignment is std::vector.

std::vector<Student> students;
std::vector<Course*> courseList;

Vector of Objects vs Vector of Pointers

Type Meaning
std::vector<Student> Stores full student objects
std::vector<Student*> Stores addresses of existing student objects 
students.push_back(Student("Tom", 1001));
courseList.push_back(&oopCourse);
In aggregation, pointer containers are common because you usually want to connect existing objects rather than duplicate them.

6. File I/O

Use file I/O to read student, course, or program data from a file and maybe save updated results.

#include <fstream>

std::ifstream file("students.txt");
if (!file) {
    std::cout << "Cannot open file" << std::endl;
}

Reading Line by Line

std::string line;
while (getline(file, line)) {
    std::cout << line << std::endl;
}

Writing to a File

std::ofstream outFile("output.txt");
outFile << "Student saved" << std::endl;
Always check whether the file opened successfully before using it.

7. Error Handling

Error handling keeps your program safe when something goes wrong.

  • File not found
  • Invalid mark
  • Student not found
  • Bad input data
if (mark < 0 || mark > 100) {
    throw std::invalid_argument("Mark must be between 0 and 100");
}
try {
    throw std::runtime_error("File error");
}
catch (const std::exception& e) {
    std::cout << e.what() << std::endl;
}
Use simple if checks for small problems, and use throw when you want the error to be handled elsewhere.

8. Algorithms

STL algorithms help you work with containers in a cleaner way.

Common Algorithms

  • std::for_each
  • std::find_if
  • std::sort
  • std::count_if
  • std::transform
std::for_each(students.begin(), students.end(), displayStudent);
auto it = std::find_if(students.begin(), students.end(),
    [](const Student& s) {
        return s.getName() == "Tom";
    });

if (it != students.end()) {
    std::cout << "Found" << std::endl;
}
Important rule: if find_if does not find anything, it returns container.end().

9. Lambda

A lambda is a small unnamed function written directly where you use it.

[](const Student& s) {
    return s.getMark() >= 50;
}

Normal Function vs Lambda

bool isPassing(const Student& s) {
    return s.getMark() >= 50;
}

auto it = std::find_if(students.begin(), students.end(), isPassing);
auto it = std::find_if(students.begin(), students.end(),
    [](const Student& s) {
        return s.getMark() >= 50;
    });
Lambda is useful when the function is short and only needed in one place.

10. Function Pointer

A function pointer stores the address of a function so you can pass or call it later.

void greet() {
    std::cout << "Hello" << std::endl;
}

void (*fp)() = greet;
fp();
void displayStudent(const Student& s) {
    s.display();
}

std::for_each(students.begin(), students.end(), displayStudent);
Type Meaning
Regular function A normal named function
Function pointer A variable that stores the address of a function
Lambda An unnamed inline function

11. Mini Example

This small example connects the main ideas together.

#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

class Student {
    std::string name;
    int id;
public:
    Student(std::string n, int i) : name(n), id(i) {}

    std::string getName() const { return name; }
    int getId() const { return id; }

    void display() const {
        std::cout << id << " - " << name << std::endl;
    }
};

class Course {
    std::string code;
    std::vector<Student*> students;
public:
    Course(std::string c) : code(c) {}

    void addStudent(Student& s) {
        students.push_back(&s);
    }

    void displayStudents() const {
        std::for_each(students.begin(), students.end(),
            [](Student* s) {
                s->display();
            });
    }
};

int main() {
    Student s1("Tom", 1001);
    Student s2("Anna", 1002);

    Course oop("OOP345");
    oop.addStudent(s1);
    oop.addStudent(s2);

    oop.displayStudents();
}
This example uses classes, strings, vector, aggregation, algorithm, and lambda together.

12. Common Mistakes

1. Mixing objects and pointers

Make sure you know whether your vector stores actual objects or addresses.

2. Forgetting .end() check

After find_if, always compare with end().

3. Bad file handling

Always check if the file was opened before reading or writing.

4. Dangling pointers

Do not store pointers to objects that no longer exist.

5. Copying too much

Use references like const std::string& or const Student& when possible.

6. Long manual loops

Use STL algorithms when the assignment expects them.
